# Nutrition Procurement Decision Tree

A one-question-at-a-time tool that screens whether a purchase from the nonprofit school food service account is allowable. It covers USDA and Tennessee rules plus loaded local rules for Rutherford County Schools, Metro Nashville Public Schools, Memphis-Shelby County Schools, Knox County Schools and Murfreesboro City Schools.

- No AI. Every result comes from fixed code logic and the embedded rules database.
- Nothing you type or upload leaves your browser.
- Produces a TDOE prior approval request report or a reimbursement claim package, with an optional ZIP of uploaded quotes and receipts.

Independent tool created by Bullard Consulting LLC. It is not issued, reviewed or endorsed by the Tennessee Department of Education or USDA. Results are screening guidance, not an approval.

The whole tool is the single file `index.html`.
